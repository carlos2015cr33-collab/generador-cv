Operamos un marketplace de creadoras centrado en llamadas telefónicas y chat. Somos un equipo pequeño trabajando sobre una aplicación en producción ya establecida, no un proyecto desde cero. Nuestro stack es TypeScript de punta a punta: Next.js en el frontend, NestJS + GraphQL + PostgreSQL en el backend, y Twilio para el sistema de llamadas.

Estamos reconstruyendo el sitio de cara al cliente sobre un nuevo sistema de diseño, pantalla por pantalla, a partir de diseños ya terminados. Este rol consiste en hacer realidad esas pantallas en una aplicación en vivo, con un ingeniero senior revisando tu trabajo.

## Responsabilidades
Tomarás una pantalla desde el diseño hasta producción: la construyes sobre nuestros tokens de diseño y componentes compartidos, conectas el pequeño cambio de API que necesite, y la acompañas hasta pruebas y release.

El trabajo incluye:
- Construir páginas y componentes de cara al cliente a partir de diseños terminados
- Reemplazar estilos hardcodeados por el sistema de diseño en pantallas existentes
- Cambios pequeños en el backend para soportar una pantalla: un campo, una query, una mutation
- Corregir bugs de frontend y problemas de rendimiento por layout shift
- Si un diseño está mal, es ambiguo o rompería algo, queremos que lo digas.
